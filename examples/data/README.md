# Analytic field fixture

`tm010_demo.mat` is generated by `generate_example_map` with order 0. It is an ideal 3 GHz cylindrical TM field sampled at x,y=-60:10:60 mm and z=0:2.5:50 mm, with Ez amplitude 100000 V/m. Ez=E0 J0(kr), Btheta=-i E0 J1(kr)/c, following the phasor convention in archived `F_MultipoleCav`. It has no conducting wall mask, coupler, pipe or fringe field. It is a software fixture, **not publication data**.

Regenerate into a new path with `setup_paths; generate_example_map('/tmp/tm010_demo.mat',0);`. MAT headers can differ between saves; compare numerical arrays rather than expecting byte-identical regeneration. The generator also supports orders 4 and 6 for small normalisation and transport checks.

The on-axis rigid v=c integrated voltage is E0 L sinc(kL/2), with sinc(u)=sin(u)/u. The native demo checks this high-energy limit using linear interpolation, which preserves the axial grid samples. Native cubic interpolation smooths this coarse fixture (about 6.4% lower axial amplitude in RF-Track 2.5.3); research workflows default to cubic and require grid-convergence checks. Off-axis interpolation on this coarse grid is not a precision field calculation. Embedded `metadata` records the analytic origin and parameters.
