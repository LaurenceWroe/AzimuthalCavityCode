# Archived research sources

The 252 files listed in `SOURCE_MANIFEST.json` are preserved byte-for-byte. They retain historical absolute paths, duplicate helper names, repeated parameter assignments and later experimental variants. Use maintained `configs/`, `workflows/` and `src/` for the documented entry points. This README is new archive guidance, not one of the original files.

Do not recursively add this directory to the Octave path. Work on copies when investigating the original CST or Mathematica workflows. Run `python3 tests/verify_collection.py` to check snapshot integrity.
